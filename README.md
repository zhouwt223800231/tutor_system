# 📚 家教课程管理系统 v4.0

一个专为家教老师设计的轻量级课程管理工具，纯前端实现，数据可存浏览器本地，也可通过 LeanCloud 在多台设备间同步。

## ✨ 功能特点

- **学生管理**：添加 / 编辑 / 删除学生，每位学生独立档案（姓名、年级、科目）
- **阶段（学期）整理**：每位学生下可按需自建阶段，例如 `2026 暑假课程`、`2026 秋季学期`、`2027 寒假课程`、`2027 春季学期`；课前计划、课后反馈、结课总结都按阶段集中管理，互不串扰
  - 支持添加 / 重命名 / 排序 / 删除阶段
  - 每条课程计划与课后反馈都可「移到」其他阶段，方便把旧数据或误归类的记录调整到位
- **课前计划**：按阶段表格记录课次、日期、课程内容，支持拖拽排序、前后插入
- **课后记录（修改即覆盖）**：
  - 层级大纲编辑器（支持 1 / 1.1 / 1.1.1 多级结构）
  - 点击历史记录进入「编辑态」，保存时**覆盖原记录**，不会产生重复
  - 学生表现、作业、家长反馈均可记录
- **结课总结**：按阶段自动汇总课程时间线与上课记录，寄语随阶段保存
- **导出功能**：
  - 一键复制文本（可直接粘贴到微信 / 钉钉）
  - 保存为图片（内置 html2canvas）
- **数据备份**：支持导出 / 导入 JSON 备份；导入旧版本（v3.x）备份时会自动迁移成“阶段”结构，旧内容先放入「未分类」阶段，可在之后手动归类
- **云端同步（可选）**：接入 LeanCloud 后，多个设备登录同一账号即可同步同一份数据

## ☁️ 开启多设备同步（LeanCloud，可选）

不配置时系统自动为「本地模式」，数据只保存在当前浏览器；按下面步骤配置后即可多设备同步：

1. 注册 LeanCloud（国内版 https://console.leancloud.cn 或国际版 https://console.leancloud.app ）并新建应用；
2. 在「设置 → 应用 Keys」复制 AppID / AppKey（国际版还需在「设置 → 应用信息」复制 API 服务域名作为 serverURL）；
3. 把三个值填入根目录 `js/config.js` 中的 `CLOUD_CONFIG`；
4. 打开页面，在右上角「登录 / 注册」注册一次，之后各设备用同一账号登录即可自动同步。
   - 首次登录：若云端为空会询问是否上传本机数据；若云端已有数据则以云端为准（也可在右上角手动「上传 / 下载」）。
   - 断网时数据先保存在本机，联网后自动重试同步。
   - 数据以整份数据集存入云端一个文档，读写权限仅归当前账号。

> 隐私提示：云端会保存学生姓名等敏感信息，请自行评估并妥善保管账号。

## 💾 数据说明

- 本地模式下数据保存在浏览器 **LocalStorage**，清除浏览器数据会丢失记录，请定期「导出备份」。
- 开启云端同步后，云端为同一账号下各设备的共享数据源；账号内按「最后一次保存为准」整份覆盖（个人使用足够，不做多用户冲突合并）。

## 📝 使用流程

1. **添加学生** → 点击右上角「+ 添加学生」，填写姓名、年级、科目（之后可点学生卡上的 ✎ 修改）
2. **添加阶段** → 为学生添加如 `2026 暑假课程` 的阶段（可自定义名称）
3. **课前计划** → 在「课前计划」页签中添加该阶段的课程安排
4. **课后记录** → 在「课后记录」页签中填写日期、内容大纲、表现、作业、家长反馈后保存
5. **修改反馈** → 点击历史记录即可编辑，保存会覆盖原记录
6. **导出分享** → 复制文本或保存图片发给学生 / 家长
7. **结课总结** → 每个阶段可单独生成课程时间线 + 记录概要 + 寄语并导出

## 🛠️ 技术栈

- HTML5 + CSS3 + Vanilla JavaScript
- LocalStorage 本地持久化（可选 LeanCloud 云同步）
- html2canvas（图片导出）、leancloud-storage（云端同步）均已本地内置，无需外网 CDN
