# 📚 家教课程管理系统 v4.0

一个专为家教老师设计的轻量级课程管理工具，**纯本地、无账号、无网络依赖**，所有数据只保存在浏览器中，页面部署在 GitHub Pages 供随时打开使用。

## ✨ 功能特点

- **学生管理**：添加 / 编辑 / 删除学生，每位学生独立档案（姓名、年级、科目）
- **阶段（学期）整理**：每位学生下可按需自建阶段，例如 `2026 暑假课程`、`2026 秋季学期`、`2027 寒假课程`、`2027 春季学期`；课前计划、课后反馈、结课总结都按阶段集中管理，互不串扰
  - 支持添加 / 重命名 / 排序 / 删除阶段
  - 每条课程计划与课后反馈都可「移到」其他阶段，方便把旧数据或误归类的记录调整到位
- **课前计划**：按阶段表格记录课次、日期、课程内容，支持拖拽排序、前后插入
- **课后记录（修改即覆盖）**：
  - 层级大纲编辑器（支持 1 / 1.1 / 1.1.1 多级结构）
  - 点击历史记录进入「编辑态」，保存时**覆盖原记录**，不会产生重复
  - 学生表现、作业、家长反馈均可记录
- **结课总结**：按阶段自动汇总课程时间线与上课记录，寄语随阶段保存
- **导出功能**：
  - 一键复制文本（可直接粘贴到微信 / 钉钉）
  - 保存为图片（内置 html2canvas，无需外网）
- **数据备份**：支持「导出备份 / 导入备份」，换设备时先导出 JSON，再到新设备导入即可；导入旧版本（v3.x）备份时会自动迁移成“阶段”结构，旧内容先放入「未分类」阶段，可之后手动归类

## 🔒 数据与隐私

- 本系统**不联网、无服务器、无账号**，数据只保存在当前浏览器的 LocalStorage 中。
- 清除浏览器数据会丢失记录，请**定期点击页面底部的「💾 导出备份」**保存一份 JSON。
- 换设备 / 换浏览器：旧设备「导出备份」→ 新设备打开页面后「导入备份」即可。

## 💾 数据说明

- 数据保存在浏览器 **LocalStorage**（键名 `tutor_system_data`），结构已升级为“按学生 → 按阶段”组织。
- 旧版本（v3.x）数据会在首次加载或导入时自动迁移：原课前计划与课后记录统一放入每个学生的「未分类」阶段，可手动用“移到 ▾”归类。

## 📝 使用流程

1. **添加学生** → 点击右上角「+ 添加学生」，填写姓名、年级、科目（之后可点学生卡上的 ✎ 修改）
2. **添加阶段** → 为学生添加如 `2026 暑假课程` 的阶段（可自定义名称，有快捷模板）
3. **课前计划** → 在「课前计划」页签中添加该阶段的课程安排
4. **课后记录** → 在「课后记录」页签中填写日期、内容大纲、表现、作业、家长反馈后保存
5. **修改反馈** → 点击历史记录即可编辑，保存会覆盖原记录，不会重复
6. **导出分享** → 复制文本或保存图片发给学生 / 家长
7. **结课总结** → 每个阶段可单独生成课程时间线 + 记录概要 + 寄语并导出
8. **数据备份** → 定期点底部「导出备份」；换设备用「导入备份」恢复
